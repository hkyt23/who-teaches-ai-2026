# 誰がAIを育てるか――生成AIの教育的判断の定点観測（実験資料）

日本教育学会第85回大会 課題研究「AI時代における教育知の社会的生成と共有に向けて」
報告「誰がAIを育てるか――生成AIの教育的判断の定点観測とヘテロドクサ保存の構想」（山本宏樹・大東文化大学）の実験詳細資料です。

- 3つの実験（教育信念質問紙・実践記録批評・『生徒指導提要』整合度）の説明、出題プロンプト、結果概要（グラフ・統計）、および全モデル・全試行の出力結果を収録しています。
- 実験1の主分析は提示極性ランダム化条件（36系列×50試行、2026年8月）に基づきます。固定極性測定（2026年7月）は過去波（2023・2024年）との経年比較用の参照として保持しています。
